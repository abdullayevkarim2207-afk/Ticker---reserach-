35% VT. Its historical return estimate is 6.58%, and its estimated volatility

The comparison cards make the mandate boundary visible. Equal weight and

historical return threshold but fails the reserve rule.

1:28 - Last-36-month window and stability failure

The most important decision test changes the estimation window to the most
recent 36 returns. The allocation changes to 85% SGOV and 15% VT, with a 6.81%
historical return estimate and 1.79% volatility.

Both portfolios pass the encoded return and reserve rules, but SGOV and VT each

A one-point reduction in VT's return estimate and a 25-basis-point annual cost

3:08 - Pilot ownership, monitoring, and kill rule

The portfolio analyst owns the pilot and reports monthly to the CIO. The pilot
runs for three monthly decision cycles with a notional $100,000 portfolio and
zero client capital.

Each cycle must monitor data lineage, every encoded mandate rule, both
estimation windows, return estimates, modeled costs, turnover, allocation
changes, and the DGS10 watch.

Kill the pilot if a lineage or mandate check fails, if no feasible portfolio
exists, or if any predeclared estimate, cost, or window stress moves a weight
by more than 10 percentage points.

3:54 - Limitations blocking live use

This system cannot establish that the strategy will earn 6.5% after costs, that
the selected weights are stable, or that historical volatility captures
prospective loss risk. Sleeve-level weights also cannot establish issuer
concentration, five-day liquidity, turnover, or the undefined calendar-loss
promise. Those limitations block live use.

The fact that both constrained portfolios clear the historical return threshold
is not enough. 6.5% is an in-sample estimate, not a promised after-cost return,
and the reasonable window change produces an unstable 20-point allocation move.
